# Color in UI Design

An interactive, 20-slide frontend engineering presentation about building intentional color systems for real web applications.

## Run locally

```sh
npm install
npm run dev
```

## Controls

- `ArrowRight` or `Space`: next slide
- `ArrowLeft`: previous slide
- `Home` / `End`: first / last slide
- `F`: toggle fullscreen
- `Esc`: exit fullscreen and close the shortcuts panel
- `?`: show keyboard shortcuts

The deck is organized into five acts that follow the same order as the live refactor demo:

1. **Palette** — HSL, the color wheel, harmonies, and an 11-step color scale
2. **Hierarchy** — color roles, visual hierarchy, and the 60–30–10 rule
3. **Meaning & access** — semantic colors, WCAG contrast, and never relying on color alone
4. **System** — design tokens, CSS variables, component variants, and dark mode as a second token set
5. **Apply it** — common mistakes, a step-by-step UI refactor, and a shipping checklist

An agenda slide after the intro links to each act. The footer shows the current act, and the progress bar marks where each act begins.
