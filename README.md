# Color in UI Design

An interactive, 20-slide frontend engineering presentation about building intentional color systems for real web applications.

## Run locally

```sh
npm install
npm run dev
```

## Controls

- `ArrowRight` or `Space`: next slide
- `ArrowLeft`: previous slide
- `Home` / `End`: first / last slide
- `F`: toggle fullscreen
- `Esc`: exit fullscreen and close the shortcuts panel
- `?`: show keyboard shortcuts

The presentation includes a selectable SVG color wheel, HSL controls, live WCAG contrast checks, palette relationships, adjustable design tokens and color scales, light/dark mode, a progressive UI refactor, and an interactive shipping checklist.
